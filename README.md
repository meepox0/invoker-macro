# 🪶 Invoker Combo Builder
!Работает только на английской раскладке
Программа-макрос для Dota 2 (Invoker), с поддержкой кастомных биндов способностей, авто-определения уровня и количества Quas через OCR, а также патчера дистанции камеры.

## 📋 Возможности

- 🎯 **Комбо для Invoker** — заранее настроенные последовательности скиллов (Sun Strike, Chaos Meteor, Tornado+EMP и т.д.)
- 🎮 **Кастомные бинды** — можно повесить любое комбо на любую клавишу или кнопку мыши
- 📊 **5 вкладок с комбо-сетами** — под разные билды и ситуации
- 🖱 **Drag & Drop инвентарь** — перетаскивай комбо из инвентаря в рабочую область и настраивай порядок
- 🤖 **Авто-определение уровня** (OCR) — уровень героя читается прямо с экрана (ФУНКЦИЯ ВРЕМЕННО НА ДОРАБОТКЕ)
- 🌀 **Авто-определение количества Quas** (OCR) — количество сфер Quas определяется по жёлтым точкам на HUD (ФУНКЦИЯ ВРЕМЕННО НА ДОРАБОТКЕ)
- 🌪 **Умный тайминг** — учёт задержки после Tornado (зависит от кол-ва Quas) и уровня героя (Необходимо в ручную ввести уровень quas в перемеенную TORNADO)
- 🔁 **Возобновление комбо** — если отпустить клавишу и нажать снова в течение 15 секунд, комбо продолжится с того же места
- 🌍 **3 языка** — Русский, Українська, English
- 🎨 **3 темы** — Чёрный-Красный, Чёрный-Белый, Серый-Чёрный
- 📌 **Поверх всех окон** + кастомный title bar + сворачивание
- 📷 **Патчер дистанции камеры** — автоматически скачивает и запускает `Dota2Patcher`

---

## 🖥 Требования

- **Windows 10 / 11** (используется `winreg`, `ctypes.windll.shell32`)
- **Python 3.9+** (рекомендуется 3.10–3.12)
- **Dota 2** установлена через **Steam**
- Для OCR: **Tesseract OCR** для Windows
- Для патчера камеры: **закрытая Dota 2** во время патча + права администратора (UAC)

🧠 Логика задержек
Задержка между комбо (зависит от уровня)
python
delay = 7.0 - (lvl * 0.3)
if lvl >= 6:  delay -= 0.3
if lvl >= 12: delay -= 0.3
if lvl >= 18: delay -= 0.3
Задержка после Tornado (зависит от количества Quas)
python
delay = 1.0 + quas * 0.2
Если следующее комбо в списке — EEE R D или EEE R alt+D (Sun Strike / Cataclysm), задержка уменьшается на 1.6–1.8 с для синхронизации с временем полёта врага.

🐞 Возможные проблемы
Проблема	Решение
pytesseract не находит Tesseract	Добавь tesseract.exe в PATH или пропиши путь в коде
Патчер камеры не скачивается	Проверь интернет / доступ к github.com / raw.githubusercontent.com
«Не удалось найти HEX-значение в client.dll»	Dota обновилась — дождись обновления патчера или используй другую версию
Клавиши не срабатывают в игре	Запусти скрипт от имени администратора (нужно для эмуляции ввода в защищённые окна)
Привязка сразу отменяется	Не используй ЛКМ/ПКМ для привязки — они отменяют режим бинда
Иконки не отображаются	Проверь папку icons и имена файлов (регистр не важен, расширение — обязательно)
OCR читает неправильно	Играй в Borderless / Windowed в том же разрешении, под которое настроены monitor-регионы в коде
Регионы OCR в коде (monitor-словари в auto_level_loop и auto_quas_loop) жёстко привязаны к разрешению экрана — при другом разрешении их нужно подгонять вручную.
